# Data Analysis and ML Projects

In this repository I have collected some of my projects related to Data Anaylisi and Data Science.

All the projects were deployed on Jupyter notebook to create a reader-friendly environment with comments and insights.

Despite the repository being updated often, the current project can be found as following.

## Data Analysis with Python and SQL

- Coursera Courses Analysis: perform an analysis on the courses provided by the famous learning platform, ranking those for number of subscribers and rate
- Mental Health Dataset Analysis: analyse the results from an online survey related mental health in the IT industry
- Spotify TOP 100 Analysis: implement SQL queries to retrieve analytics insights from the Spotify TOP chart

## Statistics

- AB Testing Cookie Monster

## Linear Regression, Classification and Machine Learning

- Stock Regression: attempt to find a linear connection among powerful metrics of a traded stock
- Wine Analysis: study the linear relationship between main features of the Vinho verde (portuguese wine)
- Travel Insurace: it attempts to fit a classification model to predict the probability of a traveller to buy an insurance based on the income
- Stroke prediction: it implements various algorithms and ML techniches to predict the likeliness to get a stroke based on main features (e.g. age, maritial status,...)
